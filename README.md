Slim Minimalistic magic lantern GUI for EOS M
=============
This is the first build of the slim, minimalistic Magic Lantern interface I've been working on for the EOS M.
I've always felt that the original Magic Lantern menu was a bit overwhelming, with a huge number of options that most people including many filmmakers rarely use.
My goal was to remove around 70% of those less frequently used features and keep only the settings that are commonly needed during shooting. I also wanted to redesign the interface to be cleaner, simpler, and more intuitive, with a minimalistic look that lets you get to important settings quickly.
I built this primarily for my own workflow, so there will probably be features that some users rely on which I've removed or haven't implemented yet. That said, I believe the core tools that most filmmakers actually use are included.

For more details on Magic Lantern please see [http://www.magiclantern.fm/](http://www.magiclantern.fm/)
